Manifest-first installs!

Intended Use Cases

0 params

Executes:


      navigator.install();

Executes:


      <install></install>

1 param

Executes:


      navigator.install({ manifest: "https://kbhlee2121.github.io/pwa/web-install/manifest.webmanifest" });

Executes:


      <install manifest="https://kbhlee2121.github.io/pwa/web-install/manifest.webmanifest"></install>

2 params

Executes:


      navigator.install({ manifest: "https://diek.us/bubble/manifest.json", id: "https://diek.us/bubble/"});

Executes:


      <install manifest="https://diek.us/bubble/manifest.json" id="https://diek.us/bubble/"></install>

relative URLs

Relative manifest

Executes:


      navigator.install({
        manifest: "/PWA/MediaControls/App1/manifest.webmanifest",
        manifestId: "https://liahiscock.github.io/PWA/MediaControls/App1/index.html"
      });

Relative manifestid

Executes:


      <install manifest="https://liahiscock.github.io/PWA/MediaControls/App1/manifest.webmanifest"
               manifestid="/PWA/MediaControls/App1/index.html">
      </install>

Relative manifest and manifestId with surrounding whitespace

Executes:


      navigator.install({
        manifest: " \t /PWA/MediaControls/App1/manifest.webmanifest \n ",
        manifestId: " \t /PWA/MediaControls/App1/index.html \n "
      });

Relative manifestId mismatched

Executes:


      navigator.install({
        manifest: "/PWA/MediaControls/App1/manifest.webmanifest",
        manifestId: "/PWA/not-the-media-controls-app"
      });

Data Errors

Empty manifest attribute

Executes:


      <install manifest=""></install>

Whitespace-only manifest attribute

Executes:


      <install manifest=" "></install>

Empty manifestid attribute

Executes:


      <install manifest="/PWA/MediaControls/App1/manifest.webmanifest"
               manifestid="">
      </install>

1 Param, manifest missing custom id

Executes:


      navigator.install({ manifest: "https://diek.us/bubble/" });
